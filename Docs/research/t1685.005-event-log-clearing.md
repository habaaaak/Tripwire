# T1685.005 — Windows Event Log Clearing

## ATT&CK Technique

T1685.005 — Clear Windows Event Logs

## Detection Hypothesis

Attackers may clear Windows event logs to remove evidence of malicious activity.

A Windows Security event indicating that an audit log was cleared can provide evidence of this behavior.

## Relevant Telemetry

Windows Security Event Log.

Relevant event:

- Event ID 1102 — The audit log was cleared.

## Detection Logic

Detect Windows Event ID 1102.

## False Positives

Legitimate administrators may intentionally clear audit logs during troubleshooting, maintenance, or system administration.

## Validation Plan

The malicious fixture should contain Event ID 1102 and trigger the detection.

The benign fixture should contain a normal Windows event and must not trigger the detection.

## Coverage Requirement

The technique will count as proven coverage only when:

1. The Sigma rule validates successfully.
2. The malicious fixture triggers the rule.
3. The benign fixture does not trigger the rule.
4. Tripwire tests pass.
