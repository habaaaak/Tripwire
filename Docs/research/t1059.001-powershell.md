# T1059.001 - PowerShell

## ATT&CK Mapping

Tactic: Execution

Technique: Command and Scripting Interpreter

Sub-technique: PowerShell

Technique ID: T1059.001

Platform: Windows

## Detection Idea

Detect suspicious PowerShell execution that may indicate command execution, script execution, or abuse of PowerShell for malicious activity.

## Relevant Telemetry

Windows process creation telemetry.

Useful fields include:

- EventID
- Image
- CommandLine
- ParentImage
- User

## Detection Hypothesis

PowerShell execution becomes more suspicious when PowerShell is launched with encoded commands, hidden windows, or other execution-related parameters commonly associated with abuse.

## False Positive Questions

- Do administrators commonly use PowerShell with these parameters?
- What legitimate automation uses encoded PowerShell commands?
- Are there enterprise management tools that regularly launch PowerShell?
- Which PowerShell arguments should be considered suspicious?
