# T1003.001 — LSASS Memory

## ATT&CK Mapping

Tactic: Credential Access

Technique: OS Credential Dumping

Sub-technique: LSASS Memory

Technique ID: T1003.001

Platform: Windows


## Detection Idea

Detect suspicious process access to lsass.exe using
Windows Sysmon ProcessAccess telemetry.


## Relevant Telemetry

Sysmon Event ID 10 — ProcessAccess

Important fields to investigate:

- SourceImage
- TargetImage
- GrantedAccess


## Detection Hypothesis

Suspicious access to the LSASS process may indicate
attempted credential access. ProcessAccess telemetry can
be examined for unusual source processes, LSASS as the
target process, and suspicious access characteristics.


## False Positive Questions

- What legitimate programs access LSASS?
- Is simply targeting lsass.exe enough?
- Which GrantedAccess values are useful?
- What legitimate security tools could trigger this rule?
