# T1053.005 - Scheduled Task

## ATT&CK Mapping

Tactic: Persistence

Technique: Scheduled Task/Job

Sub-technique: Scheduled Task

Technique ID: T1053.005

Platform: Windows

## Detection Idea

Detect suspicious creation of Windows scheduled tasks that could be used to establish persistence.

## Relevant Telemetry

Windows Security Event ID 4698 - A scheduled task was created.

Important fields to investigate:

- TaskName
- TaskContent
- SubjectUserName
- SubjectDomainName
- ClientProcessId

## Detection Hypothesis

A newly created scheduled task may indicate persistence when the task executes a suspicious command, script, or binary, or is created under an unusual account or context.

## False Positive Questions

- What legitimate software commonly creates scheduled tasks?
- Which task names are expected in a normal Windows installation?
- Should SYSTEM-created tasks be treated as suspicious?
- What commands or scripts should increase suspicion?
- Could software updates or management tools trigger this detection?
