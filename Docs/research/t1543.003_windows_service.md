# T1543.003 - Windows Service

## ATT&CK Mapping

Tactic: Persistence

Technique: Create or Modify System Process

Sub-technique: Windows Service

Technique ID: T1543.003

Platform: Windows

## Detection Idea

Detect suspicious creation or modification of Windows services that could be used to establish persistence.

## Relevant Telemetry

Windows Security service installation events.

Useful fields include:

- EventID
- ServiceName
- ImagePath
- AccountName

## Detection Hypothesis

A newly created Windows service is suspicious when its service configuration points to an unusual executable or location rather than a normal system service.

## False Positive Questions

- Are legitimate software installers creating services?
- Are administrative tools regularly creating services?
- Which service executable paths are expected?
- Could software updates legitimately create or modify services?
