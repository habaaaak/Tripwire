# T1003.003 — NTDS

## Technique

**MITRE ATT&CK:** T1003.003 — NTDS

**Tactic:** Credential Access

## Description

T1003.003 involves obtaining credential material from the Active Directory
NTDS database (`ntds.dit`). Attackers may attempt to extract this database
and obtain password hashes for domain accounts.

## Detection Approach

Tripwire detects suspicious use of tools associated with NTDS database
extraction, including:

- `ntdsutil.exe`
- `secretsdump.exe`

The detection also looks for `ntds.dit` in the command line.

## Validation

Tripwire uses malicious and benign fixtures to validate the detection.

Expected results:

- Malicious fixture → `True`
- Benign fixture → `False`

Automated tests confirm the detection behaves as expected.

## False Positives

Possible legitimate activity includes:

- Active Directory backup operations
- Authorized domain controller maintenance
- Security or diagnostic tools
